flowchart TD
    S([开始]) -->|云端推送| sent[sent]

🔍 图4：一个完整 Tick 内的详细时序

flowchart TD
    START([tick 开始])
    START --> HPR{HasPendingReminders?}
    HPR -->|FAILURE| END([等待下个tick])
    HPR -->|SUCCESS| LNR[LoadNextReminder
取最早提醒→写黑板]
    LNR --> CTC{CheckTimeCondition?}
    CTC -->|FAILURE| END
    CTC -->|SUCCESS| MS1[MarkStatus executing]
    MS1 --> RS1[ReportStatus executing]
    RS1 --> CRT{CheckReminderTimeout?}
    CRT -->|SUCCESS 超时| MSF[MarkStatus failed]
    MSF --> RSF[ReportStatus failed]
    RSF --> END
    CRT -->|FAILURE 未超时| CPP{CheckPersonPresent?}
    CPP -->|FAILURE 无人| END
    CPP -->|SUCCESS 有人| BRT[BuildReminderTts]
    BRT --> PRA[PlayReminderAudio]
    PRA -->|SUCCESS| MSC[MarkStatus completed]
    MSC --> RSC[ReportStatus completed]
    RSC --> CR2{CheckRepeating?}
    CR2 -->|SUCCESS| RR[RescheduleRepeating]
    RR --> END
    CR2 -->|FAILURE| PR[PublishResponse]
    PR --> END
