# PHP 是什么？

PHP（全称 **PHP: Hypertext Preprocessor**）是一种**服务器端脚本语言**，主要用于 Web 开发。

> **浏览器收到的 HTML 页面，可能是 PHP 生成的。**

---

## 工作原理

```text
用户浏览器 ← HTML/CSS/JS ← 服务器执行 PHP 代码 → 数据库
```

PHP 在服务器上执行完、输出完 HTML 才发给浏览器，用户看不到 PHP 源码。

---

## 典型用法

```php
<?php
// 从数据库取用户列表
$users = $db->query("SELECT * FROM users");

foreach ($users as $user) {
    echo "<li>{$user['name']}</li>";
}
?>
```

---

## 主要特点

| 特点 | 说明 |
|------|------|
| **嵌入式** | 直接写在 HTML 里，用 `<?php ?>` 包起来 |
| **动态网页** | 连接数据库、处理表单、管理 Session |
| **简单粗暴** | 上手极快，写个留言板 20 行代码搞定 |
| **生态成熟** | WordPress（全球 40%+ 网站）、Laravel、Symfony |
| **全栈自带** | 处理请求 → 连数据库 → 渲染页面，一个语言搞定 |

---

## 应用现状

✅ **适合：**
- 内容型网站（博客、企业站、新闻）
- WordPress 生态项目
- 快速出活的小型 Web 应用
- 运维管理后台
- 接外包单（客户很多点名要 PHP）

❌ **不太适合：**
- 实时应用（聊天、游戏）
- 高并发 API 网关
- 计算密集 / 机器学习

---

## 语言类比

| 语言 | 定位 |
|------|------|
| **PHP** | 端盘子的 — 从数据库端菜到网页，快、稳、不挑活 |
| **Node.js** | 同时端菜 + 实时传话（WebSocket） |
| **Python** | 端菜的同时还能分析菜品营养（数据处理） |
| **Java** | 米其林后厨 — 规矩多但扛得住大场面 |
