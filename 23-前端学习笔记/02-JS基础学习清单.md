# JavaScript 基础 — 学 React 前必须掌握

按重要程度和学习顺序排列，🔥 为核心必学项。

---

## 1. 🔥 变量声明：let / const / var

```js
const name = '小夏'     // 不能重新赋值 → 默认首选
let count = 0           // 需要改值的时候用
count = 1               // ✅ 可以改
```

**重点理解：**
- `const` 是引用不可变，但对象/数组内容可以变
- 块级作用域 vs `var` 的函数作用域

---

## 2. 🔥 箭头函数

React 里无处不在。

```js
// 普通函数
function add(a, b) { return a + b }

// 箭头函数
const add = (a, b) => a + b
const square = x => x * x        // 一个参数可去括号
const noop = () => {}            // 无参数
```

**重点理解：**
- 箭头函数没有自己的 `this`
- 简洁语法：一个表达式自动 return

---

## 3. 🔥 解构赋值

```js
// 数组解构 — useState 就是这种
const [count, setCount] = useState(0)

// 对象解构
const person = { name: '小夏', age: 18 }
const { name, age } = person

// 函数参数解构 — React 组件 props 常用
function Card({ title, onClick }) {
  return <div onClick={onClick}>{title}</div>
}
```

---

## 4. 🔥 展开运算符 ...

```js
// 数组
const arr1 = [1, 2, 3]
const arr2 = [...arr1, 4, 5]     // [1,2,3,4,5]

// 对象 — React setState 更新不可变数据
const user = { name: '小夏', age: 18 }
const updated = { ...user, age: 19 }
```

---

## 5. 🔥 模板字符串

```js
const name = '小夏'
const greeting = `你好，${name}！现在是 ${new Date().getHours()} 点`
```

---

## 6. 🔥 数组方法：map / filter / reduce

```js
const items = ['苹果', '香蕉', '橘子']

// map — 把数组变成 JSX 元素（最常见）
items.map((item, index) => <li key={index}>{item}</li>)

// filter — 过滤数据
const cheapItems = items.filter(item => item.price < 10)

// reduce — 聚合计算
const total = items.reduce((sum, item) => sum + item.price, 0)

// find / some / every — 也常用
```

---

## 7. 🔥 三元运算符 ? : 和 &&

```js
// 三元
{isLoggedIn ? <UserPanel /> : <LoginButton />}

// && 短路 — 条件为真才渲染
{unreadCount > 0 && <Badge>{unreadCount}</Badge>}
```

---

## 8. 🔥 Promise + async/await

```js
// async/await
async function loadUsers() {
  const res = await fetch('/api/users')
  const data = await res.json()
  return data
}
```

---

## 9. ⭐ import / export 模块化

```js
import React, { useState } from 'react'
import Header from './Header'
import { Button, Card } from './components'
```

---

## 10. ⭐ 了解 this 和作用域

箭头函数没有自己的 `this`，它会捕获外层上下文的 `this`。

---

## ❌ 不需要先学的

- `class` 面向对象（React 现在全是函数组件）
- `prototype` 原型链（了解即可，不用深钻）
- `Generator` / `Proxy` / `Reflect`
- `this` 的 `bind/call/apply`

---

## 学习路线建议

```
基础（1周）
  let/const → 箭头函数 → 解构 → 展开运算符 → 模板语法
    ↓
核心（1周）
  map/filter → 三元/&& → Promise/async-await
    ↓
上手 React（同时巩固）
  import/export → React 官方教程的"Tic-Tac-Toe"走一遍
```

> 标 🔥 的 8 个概念，每个花 5 分钟理解，然后直接写 React。边用边学效率最高。
