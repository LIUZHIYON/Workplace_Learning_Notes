## 一、引入

**原文大意：**
> 行为树跟状态机一样，本质上就是一个在正确时机、正确条件下调用**回调函数**的机制。回调里做什么由你决定。
> 
> 我们会把"调用回调"和"tick"这两个说法混着用。
> 
> 教程里所有 Action 基本只打印信息或 sleep，但实际项目里会做更复杂的事。

**我的解释：**

这篇就是 **"hello world"** 版本的行为树——不讲复杂概念，只让你看到：
- 怎么定义一个 Action 节点
- 怎么写到 XML 里
- 怎么在 C++ 中加载并运行它

## 二、要创建的树

树的结构（原文的 SVG 图）：

```
            Sequence
      ┌───────┼───────┬───────┐
      │       │       │       │
 CheckBattery OpenGripper ApproachObject CloseGripper
 (Condition)  (Action)   (Action)       (Action)
```

**执行流程：**
```
Step 1: CheckBattery   → 检查电池，OK 就继续
Step 2: OpenGripper    → 打开夹爪
Step 3: ApproachObject → 靠近物体
Step 4: CloseGripper   → 关闭夹爪
```

## 三、怎么创建 ActionNode（两种方式）

### 方式 A：继承（推荐）

```cpp
// 继承 BT::SyncActionNode，重写 tick()
class ApproachObject : public BT::SyncActionNode
{
public:
  ApproachObject(const std::string& name)
      : BT::SyncActionNode(name, {})   // {} = 没有端口
  {}

  // 必须重写的虚函数 tick()
  BT::NodeStatus tick() override
  {
    std::cout << "ApproachObject: " << this->name() << std::endl;
    return BT::NodeStatus::SUCCESS;
  }
};
```

**几点注意：**
- 每个 TreeNode 都有个 `name`（给人看的，**不需要唯一**）
- `tick()` 是真正执行动作的地方
- 必须返回 `NodeStatus`：`SUCCESS` / `FAILURE` / `RUNNING`

### 方式 B：函数指针（依赖注入）

```cpp
// 写法 1：普通函数
BT::NodeStatus CheckBattery()
{
  std::cout << "[ Battery: OK ]" << std::endl;
  return BT::NodeStatus::SUCCESS;
}

// 写法 2：类的成员函数
class GripperInterface {
public:
  NodeStatus open() {
    std::cout << "GripperInterface::open" << std::endl;
    return NodeStatus::SUCCESS;
  }
  NodeStatus close() {
    std::cout << "GripperInterface::close" << std::endl;
    return NodeStatus::SUCCESS;
  }
};
```

**我的解释：两种方式的区别**

| 方式 | 什么时候用 |
|---|---|
| **继承** `SyncActionNode` | 节点需要自己的状态、端口等，正式项目都用这个 |
| **函数指针** | 已经有一个现成的类/函数了，不想再包一层，直接注册进去 |

## 四、加载 XML 创建树

**XML 文件 `my_tree.xml`：**

```xml
<root BTCPP_format="4">
    <BehaviorTree ID="MainTree">
        <Sequence name="root_sequence">
            <CheckBattery   name="check_battery"/>
            <OpenGripper    name="open_gripper"/>
            <ApproachObject name="approach_object"/>
            <CloseGripper   name="close_gripper"/>
        </Sequence>
    </BehaviorTree>
</root>
```

**C++ 端：**

```cpp
int main()
{
  BT::BehaviorTreeFactory factory;

  // 注册自定义节点 —— XML 标签名 = 注册名
  // 方式 A（继承）：
  factory.registerNodeType<ApproachObject>("ApproachObject");

  // 方式 B（函数指针）：
  factory.registerSimpleCondition("CheckBattery", std::bind(CheckBattery));

  // 方式 B（类成员函数）：
  GripperInterface gripper;
  factory.registerSimpleAction("OpenGripper",
    std::bind(&GripperInterface::open, &gripper));
  factory.registerSimpleAction("CloseGripper",
    std::bind(&GripperInterface::close, &gripper));

  // 从 XML 文件创建树
  auto tree = factory.createTreeFromFile("my_tree.xml");

  // 执行树 —— tick 一次
  tree.tickOnce();
  // 或者一直跑
  // tree.tickWhileRunning();
}
```

**我的解释：注册和加载的对应关系：**

```
XML 里的标签名         C++ 里注册的名字
<CheckBattery/>    ←→  factory.registerSimpleCondition("CheckBattery", ...)
<OpenGripper/>     ←→  factory.registerSimpleAction("OpenGripper", ...)
<ApproachObject/>  ←→  factory.registerNodeType<ApproachObject>("ApproachObject")
<CloseGripper/>    ←→  factory.registerSimpleAction("CloseGripper", ...)
```

## 五、完整的可运行示例

原文最后给了一个完整的 main.cpp。

```cpp
#include "behaviortree_cpp/bt_factory.h"

// ...（上面写的所有的节点定义：CheckBattery、GripperInterface、ApproachObject）

int main()
{
  BT::BehaviorTreeFactory factory;

  // 注册自定义节点
  factory.registerNodeType<ApproachObject>("ApproachObject");

  factory.registerSimpleCondition("CheckBattery",
    std::bind(CheckBattery));

  GripperInterface gripper;
  factory.registerSimpleAction("OpenGripper",
    std::bind(&GripperInterface::open, &gripper));
  factory.registerSimpleAction("CloseGripper",
    std::bind(&GripperInterface::close, &gripper));

  // 从 XML 文件加载树
  auto tree = factory.createTreeFromFile("my_tree.xml");

  // tick 执行，直到树返回 SUCCESS 或 FAILURE
  tree.tickWhileRunning();

  return 0;
}
```

**完整执行流程：**

```
第1次 tick：
  Sequence tick
    → CheckBattery tick   → 打印 "[ Battery: OK ]" → SUCCESS
    → OpenGripper tick    → 打印 "GripperInterface::open" → SUCCESS
    → ApproachObject tick → 打印 "ApproachObject: approach_object" → SUCCESS
    → CloseGripper tick   → 打印 "GripperInterface::close" → SUCCESS
  → Sequence 返回 SUCCESS
  → 树执行完毕
```

## 六、这篇在学什么

| 你在学 | 对应代码 |
|---|---|
| 怎么定义一个 Action 节点 | `class ApproachObject : public BT::SyncActionNode` |
| 怎么用函数注册一个节点 | `factory.registerSimpleAction(...)` |
| XML 怎么引用 C++ 注册的节点 | `<CheckBattery/>` → `"CheckBattery"` |
| 怎么从 XML 创建树 | `factory.createTreeFromFile("my_tree.xml")` |
| 怎么让树跑起来 | `tree.tickOnce()` 或 `tree.tickWhileRunning()` |

## 七、你自己动手的步骤

```
Step 1: 写 C++ 代码（继承或函数定义节点）
Step 2: 写 XML 文件（定义树结构）
Step 3: 在 main 里：
  3a. 创建 factory
  3b. 注册所有节点（跟 XML 标签名一致）
  3c. 加载 XML 创建树
  3d. tickOnce() 或 tickWhileRunning()
Step 4: 编译运行
```

**如果编译：**

```bash
g++ main.cpp -o first_bt -I/path/to/behaviortree_cpp/include -L/path/to/lib -lbehaviortree_cpp
./first_bt
```

或者在 CMake 里：

```cmake
find_package(behaviortree_cpp REQUIRED)
add_executable(first_bt main.cpp)
target_link_libraries(first_bt BT::behaviortree_cpp)
```
