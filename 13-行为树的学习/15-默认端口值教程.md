# Tutorial 12: Default Port values 逐段解释

> 来源：https://behaviortree.dev/docs/tutorial-advanced/tutorial_12_default_ports
> 说明：Advanced 系列第一篇。这篇讲的是**端口的默认值**——如果 XML 里没给这个端口传值，节点就用 C++ 代码里定义的默认值。

---

## 一、引入

**原文大意：**
> 定义端口时，给它设一个**默认值**会非常方便。这样如果 XML 里没有指定该端口的值，节点就使用默认值。
>
> 注意：部分功能需要 BT.CPP **4.5.2** 或更高版本。

**我的解释：**

之前教程里，如果一个端口没有在 XML 里赋值，节点 tick 时 `getInput()` 会返回错误。有了默认值，端口变成**可选项**，XML 里不写也照样跑。

---

## 二、InputPort 默认值——3 种写法

```cpp
static PortsList providedPorts()
{
  return {
    // (1) 没有默认值 → 必须传（跟之前一样）
    InputPort<Point2D>("input"),

    // (2) 用 C++ 对象做默认值
    InputPort<Point2D>("pointA", Point2D{1,2}, "default value is x=1, y=2"),

    // (3) 用字符串做默认值（自动走 convertFromString）
    InputPort<Point2D>("pointB", "3,4", "default value is x=3, y=4"),

    // (4) 默认指向黑版里的 {point}
    InputPort<Point2D>("pointC", "{point}", "default: BB entry {point}"),

    // (5) 端口名跟黑版 key 同名时用 {=}
    InputPort<Point2D>("pointD", "{=}", "default: BB entry {pointD}"),
  };
};
```

**我的解释：5 种情况的对比：**

| 端口 | XML 里必须写？ | 如果没写，默认值是多少 |
|---|---|---|
| `input` | **必须** | 没有默认值，不写会报错 |
| `pointA` | 可选 | `Point2D{1, 2}` |
| `pointB` | 可选 | 字符串 `"3,4"` → `convertFromString` → `Point2D{3, 4}` |
| `pointC` | 可选 | 指向黑版的 `{point}` |
| `pointD` | 可选 | 指向黑版的 `{pointD}`（端口名 == 黑版 key） |

**`{=}` 是语法糖：**

```cpp
InputPort<Point2D>("pointD", "{=}", "...");
// 等价于：
InputPort<Point2D>("pointD", "{pointD}", "...");
```

---

## 三、几种默认值写法的等价关系

**写法 1 和写法 2 等价（前提：convertFromString 实现了）：**

```cpp
// 如果 convertFromString<Point2D> 能解析 "3,4" 为 Point2D{3,4}
// 那这两行效果一样：

InputPort<Point2D>("pointB", "3,4", "...");
// 相当于：
InputPort<Point2D>("pointB", Point2D{3, 4}, "...");
```

---

## 四、OutputPort 默认值

**原文：**
> 输出端口限制多一些——只能指向一个黑版 entry。

```cpp
static PortsList providedPorts()
{
  return {
    // 默认输出到黑版 {target}
    OutputPort<Point2D>("result", "{target}", "default output to {target}"),
  };
};
```

**也可以用 `{=}`：**

```cpp
OutputPort<Point2D>("result", "{=}", "...");
// 等价于：
OutputPort<Point2D>("result", "{result}", "...");
```

**我的解释：**

| 端口 | 如果 XML 里没写 remap | 输出会写到 |
|---|---|---|
| `result` | `OutputPort<Point2D>("result", "{target}")` | 黑版 `{target}` |
| `result` | `OutputPort<Point2D>("result", "{=}")` | 黑版 `{result}`（同名） |

---

## 五、实战意义

**之前的做法（必须显式赋值）：**

```xml
<MyNode input="1,2" pointA="3,4"/>
```

**有默认值后（可以简化 XML）：**

```xml
<MyNode input="1,2"/>
<!-- pointA 没写，自动用默认值 Point2D{1,2} -->
```

**什么时候用：**

| 场景 | 怎么做 |
|---|---|
| 大部分情况都用同一个值 | 设默认值，偶尔需要改时才在 XML 里覆盖 |
| 这个值几乎每次都从黑版读 | 默认值指向 `{key}` 或 `{=}` |
| 这个值必须显式指定 | 不设默认值（XML 里必须写） |
