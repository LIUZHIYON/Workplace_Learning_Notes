# Tutorial 14: Subtree Models and autoremap 逐段解释

> 来源：https://behaviortree.dev/docs/tutorial-advanced/tutorial_14_subtree_model
> 说明：Tutorial 06 讲了手动 remap。这篇讲怎么**避免重复写 remap**——用默认 remap 和 `_autoremap`。

---

## 一、重复 remap 的问题

**原文大意：**
> 同一个 SubTree 在多个地方使用时，每次都要复制粘贴同样的一堆 remap 属性：

```xml
<SubTree ID="MoveRobot" target="{move_goal}"
                        frame="world"
                        result="{error_code}"/>
<SubTree ID="MoveRobot" target="{another_goal}"
                        frame="world"
                        result="{error_code}"/>
<!-- 每次都要写 frame 和 result → 重复！ -->
```

**我的解释：** 之前的 Tutorial 06 要求每次引用子树都要显式写出所有端口 remap。但如果大部分情况 remap 都一样，写 10 次就太烦了。

---

## 二、用 TreeNodesModel 定义默认 remap

**在 XML 底部加一段 `TreeNodesModel`，给子树的端口设默认 remap：**

```xml
<TreeNodesModel>
    <SubTree ID="MoveRobot">
        <input_port  name="target"  default="{move_goal}"/>
        <input_port  name="frame"   default="world"/>
        <output_port name="result"  default="{error_code}"/>
    </SubTree>
</TreeNodesModel>
```

**之后引用时，如果跟默认一样就可以省略：**

```xml
<!-- 只用写跟默认不同的 -->
<SubTree ID="MoveRobot"/>
<!-- 等价于：target="{move_goal}" frame="world" result="{error_code}" -->
```

**需要覆盖某个值：**

```xml
<!-- frame 改用 map，其他用默认 -->
<SubTree ID="MoveRobot" frame="map"/>
<!-- 等价于：target="{move_goal}" frame="map" result="{error_code}" -->
```

---

## 三、`_autoremap="true"`——自动同名 remap

**原文：**
> 如果子树的端口名和父树黑版的 key 名**完全一样**，可以用 `_autoremap`，一句搞定：

**之前的写法（每个端口都要写）：**

```xml
<SubTree ID="MoveRobot" target="{target}"
                        frame="{frame}"
                        result="{result}"/>
```

**用了 `_autoremap` 之后：**

```xml
<SubTree ID="MoveRobot" _autoremap="true"/>
```

**自动等价于：**

```
子树端口 target → 父树黑版 {target}
子树端口 frame  → 父树黑版 {frame}
子树端口 result → 父树黑版 {result}
```

**还可以部分覆盖：**

```xml
<SubTree ID="MoveRobot" _autoremap="true" frame="world"/>
<!-- target 和 result 自动 remap，frame 用固定值 "world" -->
```

## 四、私有黑版条目（Private Entries）

**注意框原文：**
> `_autoremap="true"` 会 remap 子树里**所有**黑版条目，但**名字以 `_` 开头的除外**。

**我的解释：**

```
子树内部的 Ports：
  target   → 会被 autoremap 到父树的 {target}
  frame    → 会被 autoremap 到父树的 {frame}
  result   → 会被 autoremap 到父树的 {result}
  _private → 不会 remap！只有子树内部能访问
  _local   → 不会 remap！
```

**这可以用来标记"私有"数据——子树内部用，不让父树看到。**

---

## 五、三种 remap 方式的对比

| 方式 | 语法 | 适用场景 |
|---|---|---|
| **手动 remap**（Tutorial 06） | `target="{move_goal}"` | 端口名跟父树 key 名不同 |
| **模型默认 remap**（本篇） | 在 TreeNodesModel 里设 `default` | 大部分情况相同，偶尔覆盖 |
| **autoremap**（本篇） | `_autoremap="true"` | 端口名跟父树 key 名**完全一致** |

**选型建议：**

```
端口名 = 父树 key 名？
├── 是 → 用 _autoremap="true"
└── 否
    ├── 大部分地方 remap 一样 → 用 TreeNodesModel 设默认值
    └── 每个地方 remap 都不一样 → 手动 remap（Tutorial 06）
```

---

## 跟 Tutorial 06 的关系

```
Tutorial 06：手动 remap（每个端口显式写出）
Tutorial 14：自动 remap（默认值 + _autoremap）
                ↑ 简化 XML，减少重复
```

**一句话总结：**
> 在 `TreeNodesModel` 里给子树的端口设 `default`，或者用 `_autoremap="true"` 自动同名匹配，都可以避免重复写 remap 属性。名字以 `_` 开头的端口不会被 autoremap，成为子树的私有数据。
