# Tutorial 03: Ports with generic types 逐段解释

> 来源：https://behaviortree.dev/docs/tutorial-basics/tutorial_03_generic_ports
> 说明：上一篇教程用 `std::string` 做端口类型，这篇讲怎么用你**自定义的 C++ 类型**做端口类型。

---

## 一、引入

**原文大意：**
> 前面教程的端口类型都是 `std::string`。这篇演示怎么给端口分配**自定义的 C++ 类型**。

---

## 二、核心问题

假设你有一个结构体：

```cpp
struct Position2D {
  double x;
  double y;
};
```

你想让 XML 里这么写：

```xml
<CalculateGoal goal="{GoalPosition}"/>
```

端口类型是 `Position2D`，不是 `std::string`。问题来了——**XML 里所有属性都是字符串**，库怎么把 `"{GoalPosition}"` 转成 `Position2D`？

**答案：** 你需要提供 **`convertFromString` 的模板特化**——告诉库怎么把一个字符串解析成你的自定义类型。

---

## 三、convertFromString 模板特化

**原文代码：**

```cpp
namespace BT
{
    // 模板特化：告诉 BT.CPP 怎么把字符串转成 Position2D
    template <> inline Position2D convertFromString<Position2D>(StringView str)
    {
        // 用分号分隔两个数字
        auto parts = splitString(str, ';');

        if (parts.size() != 2)
        {
            throw RuntimeError("invalid input)");
        }
        else
        {
            Position2D output;
            output.x = convertFromString<double>(parts[0]);  // 复用 double 的转换
            output.y = convertFromString<double>(parts[1]);
            return output;
        }
    }
} // end namespace BT
```

**我的解释：**

| 要点 | 说明 |
|---|---|
| **必须放在 `namespace BT` 里** | 模板特化必须在 `BT` 命名空间内 |
| **`StringView`** | 相当于 `std::string_view`，可以传 `std::string` 或 `const char*` |
| **`splitString`** | 库自带的字符串分割工具，按分隔符拆分 |
| **可以递归调用** | `convertFromString<double>(parts[0])` 复用了 BT.CPP 内置的 double 转换 |

**转换规则：**

```
XML 属性 "1.1;2.3"
  → convertFromString<Position2D>("1.1;2.3")
    → splitString("1.1;2.3", ';')  →  ["1.1", "2.3"]
    → convertFromString<double>("1.1") → 1.1
    → convertFromString<double>("2.3") → 2.3
    → Position2D{1.1, 2.3}
```

## 四、使用自定义类型的节点

### 写数据的节点（OutputPort）

```cpp
class CalculateGoal : public SyncActionNode
{
public:
  CalculateGoal(const std::string& name, const NodeConfig& config)
    : SyncActionNode(name, config)
  {}

  static PortsList providedPorts()
  {
    // 端口类型是 Position2D ！
    return { OutputPort<Position2D>("goal") };
  }

  NodeStatus tick() override
  {
    Position2D mygoal = {1.1, 2.3};
    setOutput<Position2D>("goal", mygoal);  // 写入黑版
    return NodeStatus::SUCCESS;
  }
};
```

### 读数据的节点（InputPort）

```cpp
class PrintTarget : public SyncActionNode
{
public:
  PrintTarget(const std::string& name, const NodeConfig& config)
    : SyncActionNode(name, config)
  {}

  static PortsList providedPorts()
  {
    // 可选：加一段人类可读的描述文本
    const char* description = "Simply print the goal on console...";
    return { InputPort<Position2D>("target", description) };
  }

  NodeStatus tick() override
  {
    auto res = getInput<Position2D>("target");
    if (!res)
    {
      throw RuntimeError("error reading port [target]:", res.error());
    }
    Position2D target = res.value();
    printf("Target positions: [ %.1f, %.1f ]\n", target.x, target.y);
    return NodeStatus::SUCCESS;
  }
};
```

**我的解释：** 使用跟 `std::string` 一模一样——`InputPort<T>` / `OutputPort<T>` / `getInput<T>()` / `setOutput<T>()`。区别只是 `T` 变了。

而且 `InputPort` 构造函数可以加第三个参数——**描述字符串**，给 Groot 可视化工具用的：

```cpp
InputPort<Position2D>("target", description)
//                 端口名 ↑      描述 ↑
```

## 五、完整示例

**XML：**

```xml
<root BTCPP_format="4">
    <BehaviorTree ID="MainTree">
       <Sequence name="root">
           <!-- 第1步：C++ 计算目标位置 -->
           <CalculateGoal goal="{GoalPosition}"/>

           <!-- 第2步：从黑版读并打印 -->
           <PrintTarget   target="{GoalPosition}"/>

           <!-- 第3步：用 Script 在 XML 里直接赋值字符串
                          库会自动调用 convertFromString<Position2D> -->
           <Script        code=" OtherGoal:='-1;3' "/>

           <!-- 第4步：从黑版读新位置并打印 -->
           <PrintTarget   target="{OtherGoal}"/>
       </Sequence>
    </BehaviorTree>
</root>
```

**执行流程：**

```
第1步：CalculateGoal
  → setOutput<Position2D>("goal", {1.1, 2.3})
  → 黑版["GoalPosition"] = Position2D{1.1, 2.3}

第2步：PrintTarget
  → getInput<Position2D>("target") 从黑版读
  → 打印 "Target positions: [ 1.1, 2.3 ]"

第3步：Script
  → code = "OtherGoal:='-1;3'"
  → 库调用 convertFromString<Position2D>("-1;3")
  → 黑版["OtherGoal"] = Position2D{-1.0, 3.0}
  → 打印 "Converting string: "-1;3""

第4步：PrintTarget
  → getInput<Position2D>("target") 从黑版读 OtherGoal
  → 打印 "Target positions: [ -1.0, 3.0 ]"
```

**最终输出：**

```
Target positions: [ 1.1, 2.3 ]
Converting string: "-1;3"
Target positions: [ -1.0, 3.0 ]
```

## 六、关键点汇总

| 要做什么 | 怎么做 |
|---|---|
| **定义自定义类型** | 普通 C++ struct/class |
| **告诉 BT 怎么从字符串解析它** | 特化 `BT::convertFromString<T>(StringView)` |
| **声明端口使用该类型** | `InputPort<Position2D>("name")` / `OutputPort<Position2D>("name")` |
| **读写端口** | `getInput<Position2D>("name")` / `setOutput<Position2D>("name", value)` |
| **XML 中传字符串** | `<Script code="key:='value'"/>` 会自动调用 convertFromString |

## 跟教程 02 的区别

```
教程 02：端口类型固定为 std::string
  InputPort<std::string>("message")

教程 03：端口类型可以是任意 C++ 类型
  InputPort<Position2D>("target")
  OutputPort<int>("count")
  InputPort<double>("threshold")
  // 任何类型都行，只要提供了 convertFromString 特化
```

**内置已经支持自动转换的类型：**
- `int`, `long`, `double`, `float`
- `bool`（支持 `"true"/"false"`, `"1"/"0"`）
- `std::string`
- `NodeStatus`
- 以及你自定义的任何类型（只要写特化）

## 七、convertFromString 还要注意

**必须放在 `namespace BT` 里：**

```cpp
// ✅ 正确
namespace BT {
    template <> inline Position2D convertFromString<Position2D>(StringView str) {
        // ...
    }
}

// ❌ 错误 — 不在 BT 命名空间里
template <> inline Position2D convertFromString<Position2D>(BT::StringView str) {
    // ...
}
```

**`StringView` 同时兼容 `std::string` 和 `const char*`：**

```cpp
convertFromString<Position2D>("1.1;2.3");    // const char*
std::string s = "1.1;2.3";
convertFromString<Position2D>(s);              // std::string — 都可以
```
