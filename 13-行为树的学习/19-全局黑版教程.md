# Tutorial 16: The global blackboard idiom 逐段解释

> 来源：https://behaviortree.dev/docs/tutorial-advanced/tutorial_16_global_blackboard
> 说明：Advanced 系列最后一篇。之前每棵子树都有自己的黑版，数据需要 remap 才能共享。这篇教你**全局黑版**——让所有子树都可以直接读写的共享数据区。

---

## 一、为什么需要全局黑版

**原文大意：**
> BT.CPP 之前一直强调"作用域隔离"——每棵子树有自己的黑版，就像函数的局部变量。但有些场景确实需要**真正的全局黑版**，所有子树不用 remap 就能直接访问：
> 
> - 单例（Singleton）和全局对象
> - 机器人的全局状态（电量、模式等）
> - 在主循环里读写的数据

> 另外，黑版本身就是一个通用的键/值存储，非常适合实现文献中说的 **"世界模型（World Model）"**——存环境状态、机器人状态和任务状态的地方。

---

## 二、黑版层级结构

**默认情况（之前学过的）：**

```
MainTree 的黑版（BB1）     ← 每个子树有自己的黑版
├── SubTreeA 的黑版（BB2） ← 需要 remap 才能跟父树通信
└── SubTreeB 的黑版（BB3） ← 需要 remap
```

**加入全局黑版后：**

```
全局黑版（global_bb）      ← 外部创建，不随树销毁
  └── MainTree 的黑版      ← 创建时传入 global_bb 作为父黑版
      ├── SubTreeA 的黑版
      └── SubTreeB 的黑版
```

**关键区别：**
- 全局黑版是**外部**创建的，它的生命周期**不依赖树**
- 子树销毁后，全局黑版里的数据还在
- 所有子树可以通过 `@` 前缀直接访问顶层黑版，**不需要 remap**

---

## 三、创建全局黑版的 C++ 代码

```cpp
// 1. 创建全局黑版（顶层）
auto global_bb = BT::Blackboard::create();

// 2. 创建主树黑版，parent 设为 global_bb
auto maintree_bb = BT::Blackboard::create(global_bb);

// 3. 创建树时传入 maintree_bb
auto tree = factory.createTree("MainTree", maintree_bb);
```

**黑版层级关系：**

```
global_bb（最顶层）             ← 你手动创建的
  └── maintree_bb               ← 传入 createTree
      ├── SubTreeA 的黑版（自动创建）
      └── SubTreeB 的黑版（自动创建）
```

**global_bb 的特点：**
```
global_bb->set("value", 42);     // 主循环写入
auto v = global_bb->get<int>("value");  // 主循环读取
// tree 销毁后，global_bb 里的数据还在
```

## 四、`@` 前缀——在 XML 里访问顶层黑版

**从 BT.CPP 4.6 开始，可以用 `@` 前缀直接访问顶层黑版：**

```xml
<!-- 从顶层黑版读取 @value -->
<PrintNumber name="main_print" val="{@value}"/>

<!-- 从顶层黑版读取 @value（子树里也不需要 remap！） -->
<PrintNumber name="sub_print" val="{@value}"/>

<!-- 脚本里也可以直接用 @ 访问顶层黑版 -->
<Script code="@value_sqr := @value * @value"/>
```

**`@` 前缀的规则：**

| XML 写法 | 访问的是 |
|---|---|
| `{@value}` | 顶层黑版里的 `value`（跳过当前子树的黑版） |
| `{value}` | 当前子树黑版里的 `value`（普通写法） |
| `@value_sqr := @value * @value` | 脚本里也访问顶层黑版 |

**所以不需要 remap！** 主树和子树里的节点都写 `{@value}`，都能访问到同一个全局黑版里的数据。

## 五、完整示例

**XML：**

```xml
<BehaviorTree ID="MainTree">
    <Sequence>
        <PrintNumber name="main_print" val="{@value}"/>
        <SubTree ID="MySub"/>
    </Sequence>
</BehaviorTree>

<BehaviorTree ID="MySub">
    <Sequence>
        <PrintNumber name="sub_print" val="{@value}"/>
        <Script code="@value_sqr := @value * @value"/>
    </Sequence>
</BehaviorTree>
```

**C++：**

```cpp
int main() {
  BehaviorTreeFactory factory;
  factory.registerNodeType<PrintNumber>("PrintNumber");
  factory.registerBehaviorTreeFromText(xml_main);

  // 创建全局黑版
  auto global_bb = BT::Blackboard::create();
  auto maintree_bb = BT::Blackboard::create(global_bb);
  auto tree = factory.createTree("MainTree", maintree_bb);

  // 主循环：每次写入 @value，tick，读取 @value_sqr
  for (int i = 1; i <= 3; i++) {
    global_bb->set("value", i);
    tree.tickOnce();
    auto value_sqr = global_bb->get<int>("value_sqr");
    std::cout << "[While loop] value: " << i
              << " value_sqr: " << value_sqr << "\n\n";
  }
  return 0;
}
```

**输出：**

```
[main_print] val: 1
[sub_print] val: 1
[While loop] value: 1 value_sqr: 1

[main_print] val: 2
[sub_print] val: 2
[While loop] value: 2 value_sqr: 4

[main_print] val: 3
[sub_print] val: 3
[While loop] value: 3 value_sqr: 9
```

**执行流程：**

```
循环 1：global_bb.value = 1
  → tick → main_print 打印 [1]
         → MySub → sub_print 打印 [1]
                  → Script → value_sqr = 1*1 = 1
  → global_bb.value_sqr = 1

循环 2：global_bb.value = 2
  → tick → main_print 打印 [2]
         → MySub → sub_print 打印 [2]
                  → Script → value_sqr = 2*2 = 4
  → global_bb.value_sqr = 4

循环 3：...
```

## 六、全局黑版 vs 端口 remap

| 维度 | 端口 remap（Tutorial 06） | 全局黑版（Tutorial 16） |
|---|---|---|
| 数据共享范围 | 父树 ↔ 子树间 | 所有子树 + 树外部 |
| 是否需要 remap | ✅ 需要在 XML 写 `port="{key}"` | ❌ 不需要，用 `{@key}` 即可 |
| 树外访问 | ❌ 不可 | ✅ 主循环直接 `global_bb->get/set` |
| 作用域隔离 | ✅ 强（子树黑版隔离） | ❌ 全局共享（小心命名冲突） |
| 适用场景 | 子树间特定数据传递 | 全局状态、世界模型 |
| 版本要求 | 所有版本 | BT.CPP 4.6+（`@` 语法） |
