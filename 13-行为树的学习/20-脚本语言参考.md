## 一、引入

**原文大意：**

## 二、赋值运算符

**四种写法**

| 语法 | 含义 | 示例 |
|---|---|---|
| `:=` | **创建或赋值**——如果黑版里没有这个 key，就新建一个 | `param_A := 42` |
| `=` | **只赋值**——如果黑版里没有这个 key，会抛异常 | `param_B = 3.14` |
| `'single quotes'` | 字符串用单引号 | `message = 'hello world'` |
| `;` | 分号分隔多条语句 | `A:=42; B:=24` |

**我的解释：**

```
:= 和 = 的区别：
  param := 42    → 黑版里没有 param，新建一个
  param = 42     → 黑版里没有 param → ❌ 抛异常！

所以第一次赋值一定要用 :=，后续可以用 =。
或者一直用 := 也没问题。
```

## 三、算术运算符

**运算符表：**

| 运算符 | 赋值版 | 说明 |
|---|---|---|
| `+` | `+=` | 加法（也支持字符串拼接） |
| `-` | `-=` | 减法 |
| `*` | `*=` | 乘法 |
| `/` | `/=` | 除法 |

**示例：**

```
param_A := 7
param_B := 5
param_B *= 2         → param_B = 10
param_C := (param_A * 3) + param_B   → param_C = 7*3+10 = 31
```

**字符串拼接（+）：**

```
msg := 'hello '
msg += 'world'       → msg = 'hello world'
```

## 四、位运算符和十六进制数

**运算符表：**

| 运算符 | 说明 |
|---|---|
| `\|` | 按位或 |
| `&` | 按位与 |
| `^` | 按位异或 |
| `~` | 按位取反（一元） |
| `0x` | 十六进制字面量 |

**示例：**

```
value := 0x7F          → value = 127
val_A := value & 0x0F  → 0x7F & 0x0F = 0x0F = 15
val_B := value | 0xF0  → 0x7F | 0xF0 = 0xFF = 255
```

**注意：** 位运算符只能用于整数，对字符串或浮点数使用会抛异常。

## 五、逻辑和比较运算符

**比较运算符：**

| 运算符 | 说明 |
|---|---|
| `==` | 相等 |
| `!=` | 不等 |
| `<` `<=` | 小于 / 小于等于 |
| `>` `>=` | 大于 / 大于等于 |

**逻辑运算符：**

| 运算符 | 说明 |
|---|---|
| `&&` | 逻辑与 |
| `\|\|` | 逻辑或 |
| `!` | 逻辑非（一元） |

**示例：**

```
val_A := true
val_B := 5 > 3            → true
val_C := (val_A == val_B)  → true
val_D := (val_A && val_B) || !val_C   → true || false = true
```

## 六、三元运算符 `?:`

```
val_B = (val_A > 1) ? 42 : 24
```

**等价于 C++ 的：** `int val_B = (val_A > 1) ? 42 : 24;`

---

## 七、布尔值

布尔值在脚本中写作 `true` 和 `false`，存入黑版时保存为 `1` 和 `0`。

**赋值：**

```
val_A = true
val_B := !false    → true（跟 val_A 一样）
```

**在 Precondition 里判断：**

```xml
<!-- 下面三种写法等价 -->
<Precondition if="val_A" else="FAILURE">
<Precondition if="val_A == true" else="FAILURE">
<Precondition if="val_A == 1" else="FAILURE">
```

**注意：** `true`/`false` 必须全小写，`True` `TRUE` 都不行。

## 八、C++ 完整示例（跟 Tutorial 09 一样）

**XML：**

```xml
<root>
    <BehaviorTree>
        <Sequence>
            <Script code=" msg:='hello world' "/>
            <Script code=" A:=THE_ANSWER; B:=3.14; color:=RED "/>
            <Precondition if="A>B && color!=BLUE" else="FAILURE">
                <Sequence>
                  <SaySomething message="{A}"/>
                  <SaySomething message="{B}"/>
                  <SaySomething message="{msg}"/>
                  <SaySomething message="{color}"/>
                </Sequence>
            </Precondition>
        </Sequence>
    </BehaviorTree>
</root>
```

**C++：**

```cpp
int main() {
  BehaviorTreeFactory factory;
  factory.registerNodeType<SaySomething>("SaySomething");

  enum Color { RED=1, BLUE=2, GREEN=3 };
  factory.registerScriptingEnums<Color>();     // 批量注册枚举
  factory.registerScriptingEnum("THE_ANSWER", 42);  // 单个注册

  auto tree = factory.createTreeFromText(xml_text);
  tree.tickWhileRunning();
  return 0;
}
```

**输出：**

```
Robot says: 42.000000
Robot says: 3.140000
Robot says: hello world
Robot says: 1.000000
```

## 九、脚本语言速查表

| 类别 | 语法 | 示例 |
|---|---|---|
| **赋值** | `:=` 创建或赋值 / `=` 仅赋值 | `x:=42` / `x=42` |
| **字符串** | 单引号 | `msg:='hello'` |
| **多条语句** | `;` 分隔 | `A:=1; B:=2` |
| **算术** | `+ - * /` 及 `+= -= *= /=` | `x+=1` |
| **字符串拼接** | `+` | `s:='a'; s+='b'` |
| **位运算** | `\| & ^ ~` | `val & 0x0F` |
| **十六进制** | `0x` 前缀 | `0x7F` |
| **比较** | `== != < <= > >=` | `A>B` |
| **逻辑** | `&& \|\| !` | `A>B && C!=D` |
| **三元** | `?:` | `(A>1)?42:24` |
| **布尔值** | `true` / `false` | `flag:=true` |
| **枚举** | 通过 `registerScriptingEnums` / `registerScriptingEnum` 注册 | `color:=RED` |

---

**一句话总结：**
> BT.CPP 脚本语言是一个迷你编程语言，支持赋值、算术、位运算、逻辑判断、三元运算符和枚举别名。主要在 `<Script>` 节点和 `<Precondition if="...">` 里使用。
