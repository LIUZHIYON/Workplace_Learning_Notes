# Integration with ROS2 逐段解释

> 来源：https://behaviortree.dev/docs/ros2_integration
> 说明：官网最后一页。教你如何把 BT.CPP 跟 ROS2 集成，使用 **BehaviorTree.ROS2** 库提供的 `RosActionNode`、`RosServiceNode`、`RosTopicSubNode`、`RosTopicPubNode` 等封装。

---

## 一、架构设计思想

**原文位置：** 开头一段

**大意：**
> 你应该有一个集中的 **"Coordinator"** ROS 节点负责行为树的执行（称为 Task Planner）。系统中其他组件都应该是"面向服务"的，把决策和业务逻辑委托给 Task Planner。

**架构图：**

```
ROS 系统架构
┌─────────────────────────────────────────────┐
│  Task Planner（Coordinator）                │
│  这是唯一的决策者，运行 BT.CPP 行为树        │
│  通过 ROS2 Action / Service / Topic 与其他  │
│  组件通信                                    │
├─────────────────────────────────────────────┤
│   ┌──────────────────┐   ┌──────────────┐  │
│   │  navigation      │   │  manipulation│  │
│   │  (Nav2)          │   │  (MoveIt2)   │  │
│   └──────────────────┘   └──────────────┘  │
│   ┌──────────────────┐   ┌──────────────┐  │
│   │  perception      │   │  other nodes │  │
│   └──────────────────┘   └──────────────┘  │
└─────────────────────────────────────────────┘
```

## 二、术语警告

**原文有一个注意框：**

> 有些词在 ROS 和 BT.CPP 里含义不同：

| 词 | ROS 里的含义 | BT.CPP 里的含义 |
|---|---|---|
| **Node** | `rclcpp::Node`（ROS 节点） | `TreeNode`（行为树节点） |
| **Action** | `rclcpp_action`（ROS2 Action） | `BT::ActionNode`（行为树的 Action 节点） |

## 三、RosActionNode\<T\>（核心！）

**原文位置：** 第一个大节

**大意：**
> 与 ROS 交互的**推荐方式**是通过 `rclcpp_action`。原因是：① 它们的 API 是异步的（不用开新线程）；② 可以被取消（对应 BT 的 `halt()`）。

**完整的 `FibonacciAction` 示例：**

```cpp
#include "behaviortree_ros2/bt_action_node.hpp"
#include "action_tutorials_interfaces/action/fibonacci.hpp"

using Fibonacci = action_tutorials_interfaces::action::Fibonacci;

class FibonacciAction : public RosActionNode<Fibonacci>
{
public:
  FibonacciAction(const std::string& name,
                  const NodeConfig& conf,
                  const RosNodeParams& params)
    : RosActionNode<Fibonacci>(name, conf, params)
  {}

  // 声明端口（合并基类的端口）
  static PortsList providedPorts()
  {
    return providedBasicPorts(
      { InputPort<unsigned>("order") }
    );
  }

  // 发送 goal 请求
  bool setGoal(Goal& goal) override
  {
    getInput("order", goal.order);
    return true;
  }

  // 收到结果时调用
  NodeStatus onResultReceived(const WrappedResult& wr) override
  {
    RCLCPP_INFO(logger(), "Result received");
    for (auto number : wr.result->sequence) {
      std::cout << number << " ";
    }
    return NodeStatus::SUCCESS;
  }

  // 通信出错时调用
  NodeStatus onFailure(ActionNodeErrorCode error) override
  {
    RCLCPP_ERROR(logger(), "Error: %d", error);
    return NodeStatus::FAILURE;
  }

  // 反馈回调
  NodeStatus onFeedback(const std::shared_ptr<const Feedback> feedback) override
  {
    for (auto number : feedback->partial_sequence) {
      std::cout << number << " ";
    }
    return NodeStatus::RUNNING;  // 仍然在运行
  }
};
```

**注册节点（传 RosNodeParams）：**

```cpp
int main()
{
  BehaviorTreeFactory factory;
  auto node = std::make_shared<rclcpp::Node>("fibonacci_action_client");

  // 创建 RosNodeParams
  RosNodeParams params;
  params.nh = node;                    // ROS 节点句柄
  params.default_port_value = "fibonacci";  // action server 名字

  // 注册（把 params 当作额外的构造参数）
  factory.registerNodeType<FibonacciAction>("Fibonacci", params);

  // 然后正常加载 XML 创建树...
}
```

**需要重写的方法总结：**

| 方法 | 调用时机 | 返回 | 作用 |
|---|---|---|---|
| **`setGoal(Goal&)`** | 每次 tick 时 | bool | 构造发给 action server 的 goal |
| **`onResultReceived(result)`** | 收到结果时 | NodeStatus | 处理结果，返回 SUCCESS/FAILURE |
| **`onFeedback(feedback)`** | 收到反馈时 | NodeStatus | 通常返回 RUNNING |
| **`onFailure(error_code)`** | 通信出错时 | NodeStatus | 默认返回 FAILURE |

## 四、RosServiceNode\<T\>（服务客户端）

**原文位置：** 第二个大节

**跟 Action 类似的模式，但用于 ROS2 Service：**

```cpp
#include "behaviortree_ros2/bt_service_node.hpp"
#include "example_interfaces/srv/add_two_ints.hpp"

using AddTwoInts = example_interfaces::srv::AddTwoInts;

class AddTwoIntsNode : public RosServiceNode<AddTwoInts>
{
public:
  // ... 构造函数跟 Action 一样 ...

  static PortsList providedPorts()
  {
    return providedBasicPorts({
      InputPort<unsigned>("A"),
      InputPort<unsigned>("B")
    });
  }

  // 填充请求
  bool setRequest(Request::SharedPtr& request) override
  {
    getInput("A", request->a);
    getInput("B", request->b);
    return true;  // 返回 true 表示可以发送
  }

  // 处理回复
  NodeStatus onResponseReceived(const Response::SharedPtr& response) override
  {
    RCLCPP_INFO(logger(), "Sum: %ld", response->sum);
    return NodeStatus::SUCCESS;
  }
};
```

## 五、RosTopicSubNode / RosTopicPubNode（话题）

**原文位置：** 页面底部（在其他节点类型部分）

### RosTopicSubNode\<T\>（订阅）

订阅话题，自动把收到的消息写入黑版：

```cpp
#include "behaviortree_ros2/bt_topic_sub_node.hpp"

class BatterySubscriber : public RosTopicSubNode<sensor_msgs::msg::BatteryState>
{
public:
  // 输入的端口名就是话题名
  static PortsList providedPorts()
  {
    return providedBasicPorts({});
  }
};
```

### RosTopicPubNode\<T\>（发布）

从黑版读数据，发布到话题：

```cpp
#include "behaviortree_ros2/bt_topic_pub_node.hpp"

class CmdVelPublisher : public RosTopicPubNode<geometry_msgs::msg::Twist>
{
public:
  static PortsList providedPorts()
  {
    return providedBasicPorts({
      InputPort<geometry_msgs::msg::Twist>("cmd")
    });
  }
};
```

## 六、BehaviorTree.ROS2 提供的模板节点速查表

| 模板 | 头文件 | 用途 | 必须重写的方法 |
|---|---|---|---|
| **`RosActionNode<T>`** | `bt_action_node.hpp` | 调用 ROS2 Action | `setGoal()`、`onResultReceived()` |
| **`RosServiceNode<T>`** | `bt_service_node.hpp` | 调用 ROS2 Service | `setRequest()`、`onResponseReceived()` |
| **`RosTopicSubNode<T>`** | `bt_topic_sub_node.hpp` | 订阅话题到黑版 | 可选：自定义回调 |
| **`RosTopicPubNode<T>`** | `bt_topic_pub_node.hpp` | 从黑版发布话题 | 可选：自定义 |

**统一注册方式（所有模板都一样）：**

```cpp
// 1. 创建 RosNodeParams
RosNodeParams params;
params.nh = ros_node;
params.default_port_value = "service_or_action_name";

// 2. 注册
factory.registerNodeType<MyNode>("MyNode", params);
```

**一句话总结整个官网文档系列：**
> BT.CPP 的 ROS2 集成通过 `BehaviorTree.ROS2` 库实现，核心是 4 个模板节点——`RosActionNode`（动作）、`RosServiceNode`（服务）、`RosTopicSubNode`（订阅）、`RosTopicPubNode`（发布）。它们都是异步的、可取消的，完美贴合 ROS2 的通信模型。🎉
