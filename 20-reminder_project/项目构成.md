## 🔴 核心文件详解

### 1. `robot_reminder_bt/` — 行为树提醒包（★最核心）

| 文件 | 作用 |
|------|------|
| **`reminder_bt_driver.py`** | 🔥 **主驱动**：订阅 `/robot/command` 话题接收提醒 → 运行行为树 → 调用 voice_bridge Action → 内嵌 ZMQ 服务器(端口1667) 供 Groot2 可视化 |
| **`bt_engine.py`** | 轻量行为树引擎：实现 Sequence/Fallback/ReactiveSequence/ActionNode/ConditionNode/AsyncActionNode，零外部依赖 |
| **`reminder_bt_nodes.py`** | 提醒专用节点：CheckNewReminder(查新提醒)、CheckTimeCondition(查时间)、MarkExecuting(标记执行)、BuildTtsText(构建语音文本)、GenerateTTS(调用 voice_bridge)、RescheduleRepeating(重复提醒)、PublishStatus(上报结果) |
| `groot2_server.py` | ZMQ Groot2 服务器（已废弃，功能已嵌入 driver） |
| `launch/reminder_bt_full.launch.py` | ROS2 启动文件 |

### 2. `backend/` — FastAPI 后端（端口 8000）

| 文件 | 作用 |
|------|------|
| `main.py` | FastAPI 应用入口，挂载路由和前端 |
| `config.py` | 数据库/TTS 参数配置 |
| `database.py` | SQLAlchemy 异步数据库 |
| `player.py` | pygame 音频播放器 |
| `routes/reminders.py` | 本地提醒 CRUD API |
| `routes/board.py` | 板子提醒 API（SSH 远程查询） |
| `routes/presence.py` | 调度器提醒处理 |
| `services/scheduler.py` | 定时检查到期提醒 |
| `services/tts.py` | TTS 语音合成（PowerShell/edge-tts） |

### 3. `management/` — 管理服务器（端口 8001）

| 文件 | 作用 |
|------|------|
| `server.py` | 管理服务器：登录、绑定宠物、**发送提醒到远程服务器+SSH直推板子话题** |
| `index.html` | 管理界面 |

### 4. `frontend/` — Web 前端

| 文件 | 作用 |
|------|------|
| `index.html` | 提醒管理页面（本地提醒/板子提醒两个 Tab） |
| `css/style.css` | 样式 |
| `js/app.js` | 前端交互逻辑 |

### 5. `tools/` — PC 端工具

| 文件 | 作用 |
|------|------|
| `bt_monitor_server.py` | BT 监控桥接（连接板子 ZMQ:1667，提供 Web 界面 :8003） |
| `viewer_server.py` | 只读提醒查看器（:8002） |

### 6. `robot_aipet_relay/` — WebSocket 中继

| 文件 | 作用 |
|------|------|
| `relay_node.py` | 连接远程服务器 WebSocket，接收 `reminder_delivery`，转发到 ROS2 话题 |

### 7. 其他目录

| 目录 | 作用 |
|------|------|
| `deploy/` | 部署脚本（`deploy.sh` 部署到板子） |
| `simulation/` | 本地模拟测试（模拟 APP + 模拟设备） |
| `speaker/` | voice_bridge 语音桥接文档 |
| `new_protocol/` | HTTP API + WebSocket 协议文档 |
| `docs/` | 补充文档 |
| `audio/` | TTS 生成的 WAV 音频文件 |

## 🚀 启动方式

### PC 端

```bash
# 后端 + 前端 (8000)
cd backend
python main.py

# 管理端 (8001)
cd management
python server.py

# BT 监控 (8003，可选)
cd tools
python bt_monitor_server.py
```

### 板子端

```bash
ssh cat@192.168.1.191
source /opt/ros/humble/setup.bash
export PYTHONPATH=~/ros2_ws/src/robot_reminder_bt:$PYTHONPATH

# 启动行为树驱动（含 ZMQ:1667）
python3 -m robot_reminder_bt.reminder_bt_driver \
  --ros-args -p tick_interval_ms:=200
```

## 🔄 数据流

```
你通过 8001 网页发提醒
  → HTTP POST → 远程服务器 47.118.26.156 创建提醒
  → SSH → 板子 /robot/command 话题
  → reminder_bt_driver 收到 (黑板 pending_reminders)
  → 每 200ms tick 行为树
  → CheckTimeCondition 到点 → GenerateTTS
  → /voice/speak Action → voice_bridge → 🎵
  → PublishStatus → 上报结果
```
