📝 registerNodes() 注册代码模板

以下代码是 registration 的部分，在现有 registerNodes() 尾部追加

// ── 提醒子系统节点注册（registerBuilder 模式）──
// 纯条件节点（无 ROS 依赖）
factory_.registerBuilder<HasPendingReminders>("HasPendingReminders",
    [](const std::string& name, const BT::NodeConfig& cfg) {
      return std::make_unique<HasPendingReminders>(name, cfg);
    });
factory_.registerBuilder<CheckPersonPresent>("CheckPersonPresent", ...);
factory_.registerBuilder<CheckReminderTimeout>("CheckReminderTimeout", ...);
factory_.registerBuilder<CheckRepeating>("CheckRepeating", ...);

// 需要 ros_node_ 的节点
auto node = ros_node_;
factory_.registerBuilder<LoadNextReminder>("LoadNextReminder",
    [node](const std::string& name, const BT::NodeConfig& cfg) {
      return std::make_unique<LoadNextReminder>(name, cfg, node);
    });
// ... CheckTimeCondition, MarkStatus, BuildReminderTts,
//     PlayReminderAudio, RescheduleRepeating 同理

// 需要 publisher 的节点
factory_.registerBuilder<PublishResponse>("PublishResponse",
    [node, pub=response_pub_](const std::string& name, const BT::NodeConfig& cfg) {
      return std::make_unique<PublishResponse>(name, cfg, node, pub);
    });
factory_.registerBuilder<ReportStatus>("ReportStatus",
    [node, pub=ws_result_pub_](const std::string& name, const BT::NodeConfig& cfg) {
      return std::make_unique<ReportStatus>(name, cfg, node, pub);
    });

🧠 优先级说明

💡 播报复用建议

提醒系统的 PlayReminderAudio 和主树的 AudioSync 都调用 /voice/speak Action。
建议：提醒子树直接复用 AudioSync 节点：
<AudioSync audio="{tts_text}"/>
少注册 1 个节点，走同一套语音队列。
