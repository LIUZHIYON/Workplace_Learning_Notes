🤔 Docker 是什么

对比传统虚拟机Docker 容器
启动速度几分钟（完整启动 OS）秒级（共享宿主内核）
硬盘占用10~20GB（完整系统）数百 MB~几 GB
内存占用2~8GB几十 MB~几百 MB
隔离级别完全隔离进程级隔离
跨平台硬件兼容性要求高Linux / Windows / Mac 统一体验
📌 一句话理解
虚拟机 = 整套房子（独立地基+水电）
Docker = 集装箱（共享地基+水电，只装你需要的东西）

📦 三大核心概念

概念类比说明
镜像 (Image)光盘 / iso 安装包一个只读模板，包含操作系统+软件+配置
容器 (Container)运行中的电脑镜像运行后的实例，有读写层，可启动/停止/删除
仓库 (Registry)应用商店存放镜像的地方，Docker Hub 是官方仓库
# 镜像 → 容器 的关系类比 # docker pull python:3.11 ≈ 下载 Python 安装包 # docker run python:3.11 ≈ 双击安装包运行 # 一个镜像可以启动多个容器，就像一张光盘可以装多台电脑

⚙️ docker run 常用参数

参数说明示例
-it交互式终端（进去后能输命令）docker run -it ubuntu bash
-d后台运行（detach）docker run -d nginx
--name指定容器名称docker run --name my_ubuntu ubuntu
-p <宿主机>:<容器>端口映射docker run -p 8080:80 nginx
-v <宿主机>:<容器>挂载目录（卷映射）docker run -v D:\data:/data ubuntu
-e <KEY=VALUE>设置环境变量docker run -e MY_VAR=hello ubuntu
--rm容器停止后自动删除docker run --rm ubuntu echo hi
--restart=always开机自启 / 崩溃自动重启docker run --restart=always nginx
--net=host使用宿主机网络（ROS2 需要）docker run --net=host ros: humble
--memory=4g限制最大使用内存docker run --memory=4g ubuntu
--cpus=2限制使用 CPU 核心数docker run --cpus=2 ubuntu
--env-file从文件加载环境变量docker run --env-file .env ubuntu
-w / --workdir指定工作目录docker run -w /my_ws ubuntu pwd
--privileged赋予容器所有权限docker run --privileged ubuntu
--device挂载硬件设备（如摄像头）docker run --device /dev/video0
# 完整示例：启动一个 ROS2 容器 docker run -it --name ros2_humble \ --net=host \ --env="DISPLAY=$env:DISPLAY" \ --env="QT_X11_NO_MITSHM=1" \ -v ${PWD}:/my_ws \ -v /tmp/.X11-unix:/tmp/.X11-unix \ osrf/ros:humble-desktop \ bash

🌐 Docker 网络模式

网络模式说明适用场景
bridge（默认）容器有独立 IP，通过网桥通信多容器间隔离通信
host容器直接使用宿主机网络ROS2 / 需要低延迟的场景 🏆
none无网络安全隔离
自定义网络docker network create 创建需要 DNS 解析的场景
# 网络管理命令 docker network ls # 列出所有网络 docker network create my_net # 创建自定义网络 docker network connect my_net 容器名 # 将容器接入网络 docker network inspect my_net # 查看网络详情 docker network rm my_net # 删除网络

📄 Dockerfile 指令大全

指令说明
FROM指定基础镜像（必选）
RUN构建时执行命令（装软件）
COPY从构建目录复制文件到镜像
ADDCOPY 增强版（支持自动解压 tar、URL）
WORKDIR设置工作目录（类似 cd）
ENV设置环境变量
ARG构建参数（构建时传入，不会留在镜像里）
EXPOSE声明容器要暴露的端口
CMD容器启动时的默认命令（可以被覆盖）
ENTRYPOINT容器启动时的固定命令（不可被覆盖）
VOLUME声明挂载点
LABEL添加元数据（版本号、作者等）
HEALTHCHECK健康检查
USER指定运行用户（非 root）
SHELL指定 RUN 使用哪种 shell
# 完整的 Dockerfile 示例 FROM osrf/ros:humble-desktop # 基础镜像 LABEL version="1.0" author="liu" # 元数据 ENV TURTLEBOT3_MODEL=waffle # 环境变量 ENV DISPLAY=:0 RUN apt update && apt install -y \ # 安装软件 ros-humble-navigation2 \ ros-humble-nav2-bringup \ ros-humble-turtlebot3-gazebo \ && rm -rf /var/lib/apt/lists/* # 清理缓存（减小镜像体积） WORKDIR /my_ws # 工作目录 COPY src/ ./src/ # 复制代码 RUN /bin/bash -c "source /opt/ros/humble/setup.bash && colcon build" CMD ["bash"] # 默认启动命令
# 构建和运行 docker build -t ros2-nav2:1.0 . # 构建镜像 docker run -it --name nav2_demo ros2-nav2:1.0 # 运行

🧹 清理命令

命令说明
docker system prune清理所有未使用的容器、网络、悬空镜像
docker system prune -a更彻底的清理（含未使用的镜像）
docker container prune只清理已停止的容器
docker image prune只清理悬空镜像
docker volume prune清理未使用的卷
docker network prune清理未使用的网络
💡 建议
定期执行 docker system prune -a 可以释放大量硬盘空间

🧩 Docker Compose（多容器编排）

用 docker-compose.yml 文件管理多个容器的启动配置，一句命令启动整个系统。

# docker-compose.yml 示例 version: '3.8' services: ros2-master: image: osrf/ros:humble-desktop container_name: ros2_humble network_mode: host environment: - DISPLAY=${DISPLAY} - QT_X11_NO_MITSHM=1 volumes: - .:/my_ws - /tmp/.X11-unix:/tmp/.X11-unix stdin_open: true tty: true command: bash database: image: postgres:15 container_name: my_db environment: POSTGRES_PASSWORD: mypass volumes: - postgres_data:/var/lib/postgresql/data volumes: postgres_data:
命令说明
docker compose up -d后台启动所有服务
docker compose down停止并删除所有服务
docker compose ps查看服务状态
docker compose logs -f跟踪所有服务的日志
docker compose build重新构建所有镜像
docker compose restart重启所有服务

🤖 ROS2 + Docker 最佳实践

# 运行 ROS2 容器（带 GUI 显示） docker run -it --name ros2_humble \ --net=host \ --env="DISPLAY=$env:DISPLAY" \ --env="QT_X11_NO_MITSHM=1" \ --env="LIBGL_ALWAYS_SOFTWARE=1" \ -v /tmp/.X11-unix:/tmp/.X11-unix \ -v ${PWD}:/my_ws \ osrf/ros:humble-desktop \ bash
🎨 GUI 显示
需要映射 DISPLAY 和 X11 socket，WSLg 会用 Wayland 自动显示窗口
📡 ROS2 通信
必须使用 --net=host，不然 ROS2 发现机制（DDS）无法跨容器通信
🗺️ 挂载工作区
用 -v 把代码挂载进去，宿主机编辑，容器里编译运行

🖥️ 架构支持（amd64 vs arm64）

平台架构拉取命令
🖥️ Windows PC / Intel Macamd64docker pull ubuntu:22.04（默认）
🧩 RK3576 / Raspberry Piarm64docker pull arm64v8/ubuntu:22.04
🍎 Apple Silicon Macarm64docker pull ubuntu:22.04（会自动拉 arm64）
💡 Docker 会自动识别架构
在 amd64 电脑上 pull ubuntu:22.04 → 自动下 amd64 版
在 arm64 电脑上 pull ubuntu:22.04 → 自动下 arm64 版
只有特定场景（如 arm64v8/ 前缀的镜像）才需要手动指定

❓ 常见问题

问题解决方法
容器一启动就退出加 -it 保持交互，或 CMD 用 tail -f /dev/null
Docker 没有权限管理员身份运行 PowerShell，或加用户到 docker 组
镜像拉取慢配置国内镜像加速（如 阿里云、中科大）
容器内能联网吗？默认 bridge 模式可以，加 --dns 8.8.8.8 可指定 DNS
容器里怎么用 GPU？装 NVIDIA Container Toolkit，加 --gpus all
如何减小镜像体积？多用 apt clean，多用多阶段构建，用 alpine 版镜像
容器和宿主机时间不同步加 -v /etc/localtime:/etc/localtime:ro
Warning 磁盘空间不足docker system prune -a 清理，或迁移 Docker 数据目录

🔄 常用工作流

📥 首次部署
pull 镜像 → run 容器
→ exec 进入
→ 装东西、改配置
🔄 日常开发
start 容器 → exec 进入
→ 编译运行 → exit
→ stop 容器
📤 打包部署
写 Dockerfile → build
→ push 到仓库
→ 在目标机器 pull + run
🧪 临时测试
pull 镜像 → run --rm
→ 测试命令
→ 容器退出后自动删除
