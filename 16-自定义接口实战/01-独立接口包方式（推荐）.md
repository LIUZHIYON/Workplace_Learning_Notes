# 方式一：独立接口包（官方推荐的最佳实践）

> **官方文档:** https://docs.ros.org/en/humble/Tutorials/Beginner-Client-Libraries/Custom-ROS2-Interfaces.html
>
> **一句话总结：** `.msg` / `.srv` 文件单独放在一个 `ament_cmake` 包里，C++ 和 Python 都能引用

---

## 🧠 核心思想

```
独立接口包                         使用包
┌────────────────────┐          ┌────────────────────┐
│ tutorial_interfaces│          │ cpp_pubsub         │
│                    │  编译    │                    │
│  msg/Num.msg ──────┼─→ 生成 ─→  find_package() ─→ │
│                    │ .cmake   │  #include 使用    │
└────────────────────┘          └────────────────────┘
```

**好处：** 接口定义和业务代码解耦，C++ 包、Python 包都能复用同一个接口。

## 📝 每个文件具体怎么写

### ① 接口包：`msg/Num.msg`

```msg
# 一行一个字段：类型 + 字段名
int64 num
```

编译后自动生成 C++：`tutorial_interfaces::msg::Num`，带 `num` 字段。

### ② 接口包：`CMakeLists.txt`

```cmake
cmake_minimum_required(VERSION 3.8)
project(tutorial_interfaces)

# ★ 必须加 ament_cmake
find_package(ament_cmake REQUIRED)
# ★ 必须加 rosidl_default_generators
find_package(rosidl_default_generators REQUIRED)

# ★ 核心宏：把 .msg 文件转成 C++/Python 代码
rosidl_generate_interfaces(${PROJECT_NAME}
  "msg/Num.msg"
)

# ★ 必须加 ament_package
ament_package()
```

> 💡 **`ament_package()` 是**生成 `.cmake` 配置文件的关键，别的包才能 `find_package()` 找到你。没有这行，编译没报错但其他包引用不了。

### ③ 接口包：`package.xml`

```xml
<?xml version="1.0"?>
<package format="3">
  <name>tutorial_interfaces</name>
  <version>0.0.0</version>
  <description>Custom interfaces</description>
  <maintainer email="ubt@todo.todo">ubt</maintainer>
  <license>Apache-2.0</license>

  <buildtool_depend>ament_cmake</buildtool_depend>

  <!-- ↓↓↓ 这三行是接口包必须的 ↓↓↓ -->
  <buildtool_depend>rosidl_default_generators</buildtool_depend>
  <exec_depend>rosidl_default_runtime</exec_depend>
  <member_of_group>rosidl_interface_packages</member_of_group>
</package>
```

### ④ 使用包：`src/publisher.cpp`（改 4 处）

```cpp
// [改动1] 头文件从标准库换成自己的
// 原来: #include "std_msgs/msg/string.hpp"
#include "tutorial_interfaces/msg/num.hpp"       // ← 换成这个

// [改动2] 发布者类型
// 原来: std_msgs::msg::String
publisher_ = this->create_publisher<tutorial_interfaces::msg::Num>("topic", 10);

// [改动3] 消息实例
auto msg = tutorial_interfaces::msg::Num();       // ← 换成自己的

// [改动4] 赋值和打印
msg.num = count_++;                               // ← 换成自己的字段
RCLCPP_INFO(this->get_logger(), "Publishing: '%ld'", msg.num);
```

### ⑤ 使用包：`CMakeLists.txt`（改 2 处）

```cmake
find_package(ament_cmake REQUIRED)
find_package(rclcpp REQUIRED)
find_package(tutorial_interfaces REQUIRED)        # ← [新增] 找到接口包

add_executable(publisher src/publisher.cpp)
ament_target_dependencies(publisher rclcpp tutorial_interfaces)  # ← [改] 加上接口包

add_executable(subscriber src/subscriber.cpp)
ament_target_dependencies(subscriber rclcpp tutorial_interfaces)  # ← [改] 加上接口包

install(TARGETS publisher subscriber DESTINATION lib/${PROJECT_NAME})
ament_package()
```

### ⑥ 使用包：`package.xml`

```xml
<buildtool_depend>ament_cmake</buildtool_depend>
<depend>rclcpp</depend>
<depend>tutorial_interfaces</depend>      <!-- ← [新增] 运行时需要 -->
```

## 🚀 编译运行

```bash
cd ~/ros2_ws

# 先编译接口包
colcon build --packages-select tutorial_interfaces

# 再编译使用包
colcon build --packages-select cpp_pubsub

# source 环境
source install/setup.bash

# 两个终端分别跑
ros2 run cpp_pubsub publisher
ros2 run cpp_pubsub subscriber
```

## ✅ 总结

| 步骤 | 做什么 |
|------|--------|
| 1 | 新建一个 `ament_cmake` 包，里面只放 `.msg`/`.srv` 文件 |
| 2 | 配好 `CMakeLists.txt`（`rosidl_generate_interfaces` + `ament_package`） |
| 3 | 配好 `package.xml`（三行接口依赖） |
| 4 | 编译接口包 |
| 5 | 在使用包代码里 `#include` 接口头文件 |
| 6 | 在使用包 `CMakeLists.txt` 加 `find_package` 和依赖 |
| 7 | 编译使用包 → 运行 |
