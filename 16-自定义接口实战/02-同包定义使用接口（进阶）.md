# 方式二：同包定义和使用接口（进阶）

> **官方文档:** https://docs.ros.org/en/humble/Tutorials/Beginner-Client-Libraries/Single-Package-Define-And-Use-Interface.html
>
> **一句话总结：** `.msg` 文件跟 C++ 节点放在同一个包里，简单省事，但 CMake 写法不一样

---

## 🧠 核心思想

```
同一个包 more_interfaces
┌─────────────────────────────────────────┐
│  msg/AddressBook.msg                    │
│  src/publish_address_book.cpp           │
│  CMakeLists.txt （要加特殊链接代码）     │
│  package.xml                            │
└─────────────────────────────────────────┘
```

**和方式一的核心区别：** 接口代码和自己节点的代码是**同时编译**的，接口还没"安装"到系统里。所以 CMake 需要用 `rosidl_get_typesupport_target` + `target_link_libraries` 手动链接，**不能**用 `find_package()`（自己还没装好，找不到）。

---

## 📦 要创建/修改哪些文件

**全部在 `more_interfaces` 包里：**

| 文件 | 操作 |
|------|------|
| `msg/AddressBook.msg` | **新建** — 写消息定义（含常量） |
| `src/publish_address_book.cpp` | **新建** — 发布者节点 |
| `CMakeLists.txt` | **修改** — 加接口生成 + 手动链接 |
| `package.xml` | **修改** — 加接口依赖 |

---

## 📝 每个文件具体怎么写

### ① `msg/AddressBook.msg`

```msg
# 支持定义常量：常量名=值
uint8 PHONE_TYPE_HOME=0
uint8 PHONE_TYPE_WORK=1
uint8 PHONE_TYPE_MOBILE=2

# 普通字段
string first_name
string last_name
string phone_number
uint8 phone_type
```

> 💡 编译后 C++ 代码里可以直接用 `msg.PHONE_TYPE_MOBILE`。
>
> ⚠️ 常量名**必须全大写**，字段名**小写**，这是 ROS2 的命名规范。

### ② `CMakeLists.txt`（最复杂的部分）

```cmake
cmake_minimum_required(VERSION 3.8)
project(more_interfaces)

# ── ① 找基础依赖 ──
find_package(ament_cmake REQUIRED)
find_package(rclcpp REQUIRED)
find_package(rosidl_default_generators REQUIRED)

# ── ② 声明有哪些 .msg 文件要编译 ──
set(msg_files
  "msg/AddressBook.msg"
)

# ── ③ 生成接口代码 ──
rosidl_generate_interfaces(${PROJECT_NAME}
  ${msg_files}
)

# ── ④ 导出运行时依赖 ──
ament_export_dependencies(rosidl_default_runtime)

# ── ⑤ 声明发布者节点 ──
add_executable(publish_address_book src/publish_address_book.cpp)
ament_target_dependencies(publish_address_book rclcpp)

# ★★★ ⑥ 关键！手动链接到同包生成的接口代码 ★★★
rosidl_get_typesupport_target(cpp_typesupport_target
  ${PROJECT_NAME} rosidl_typesupport_cpp)
target_link_libraries(publish_address_book "${cpp_typesupport_target}")

# ── ⑦ 安装 ──
install(TARGETS
  publish_address_book
  DESTINATION lib/${PROJECT_NAME}
)

ament_package()
```

> 🔥 **第⑥步是最容易忘的。** 忘记加这 3 行，编译会报"undefined reference"链接错误。
>
> **这 3 行的作用：**
> - `rosidl_get_typesupport_target` 找到 AddressBook.msg 生成了哪个 C++ 库
> - `target_link_libraries` 把你的节点链接到这个库上

### ③ `package.xml`

```xml
<?xml version="1.0"?>
<package format="3">
  <name>more_interfaces</name>
  <version>0.0.0</version>
  <description>Example of using interfaces in the same package</description>
  <maintainer email="ubt@todo.todo">ubt</maintainer>
  <license>Apache-2.0</license>

  <buildtool_depend>ament_cmake</buildtool_depend>

  <!-- ↓↓↓ 这三行是必须的 ↓↓↓ -->
  <buildtool_depend>rosidl_default_generators</buildtool_depend>
  <exec_depend>rosidl_default_runtime</exec_depend>
  <member_of_group>rosidl_interface_packages</member_of_group>

  <test_depend>ament_lint_auto</test_depend>
  <test_depend>ament_lint_common</test_depend>

  <export>
    <build_type>ament_cmake</build_type>
  </export>
</package>
```

### ④ `src/publish_address_book.cpp`

```cpp
#include <chrono>
#include <memory>

#include "rclcpp/rclcpp.hpp"
#include "more_interfaces/msg/address_book.hpp"  // ← 同包的头文件

using namespace std::chrono_literals;

class AddressBookPublisher : public rclcpp::Node
{
public:
  AddressBookPublisher()
  : Node("address_book_publisher")
  {
    publisher_ = this->create_publisher<more_interfaces::msg::AddressBook>("address_book", 10);

    timer_ = this->create_wall_timer(1s, [this]() {
      auto msg = more_interfaces::msg::AddressBook();

      // 填充字段
      msg.first_name = "John";
      msg.last_name = "Doe";
      msg.phone_number = "1234567890";
      msg.phone_type = msg.PHONE_TYPE_MOBILE;  // ← 使用消息里定义的常量

      RCLCPP_INFO(this->get_logger(), "Publishing: %s %s",
        msg.first_name.c_str(), msg.last_name.c_str());
      publisher_->publish(msg);
    });
  }

private:
  rclcpp::Publisher<more_interfaces::msg::AddressBook>::SharedPtr publisher_;
  rclcpp::TimerBase::SharedPtr timer_;
};

int main(int argc, char * argv[])
{
  rclcpp::init(argc, argv);
  rclcpp::spin(std::make_shared<AddressBookPublisher>());
  rclcpp::shutdown();
  return 0;
}
```

## 🚀 编译运行

```bash
cd ~/ros2_ws

# 编译这个包（及其所有依赖）
colcon build --packages-up-to more_interfaces

source install/setup.bash

# 运行发布者
ros2 run more_interfaces publish_address_book
```

验证：

```bash
# 另开一个终端
source ~/ros2_ws/install/setup.bash
ros2 topic echo /address_book
```

输出：

```
first_name: John
last_name: Doe
phone_number: '1234567890'
phone_type: 2    # PHONE_TYPE_MOBILE = 2
---
```

## 🔥 两种方式的对比总结

| 对比项 | **方式一：独立接口包** | **方式二：同包定义** |
|--------|----------------------|-------------------|
| 推荐程度 | ⭐⭐⭐⭐⭐ **官方推荐** | ⭐⭐ 快速测试用 |
| 接口复用 | ✅ 所有包都能引用 | ❌ 只能自己包内用 |
| CMake 复杂度 | 简单：`find_package()` | 复杂：需要 `rosidl_get_typesupport_target` + `target_link_libraries` |
| 适用场景 | 正式项目、多人协作 | 快速原型、个人实验 |
| 编译命令 | `--packages-select` + 再编译使用包 | `--packages-up-to` 一步到位 |

**选哪个？** 正式项目用方式一，就想自己跑个测试用方式二。
