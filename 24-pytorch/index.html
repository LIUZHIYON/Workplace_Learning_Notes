一、PyTorch 是什么？一句话 + 一个故事

⚡ 一句话版

PyTorch = 一个让电脑学会"猜东西"的 Python 工具包。

它帮你做两件事：搭神经网络（给电脑设计大脑结构）， 和训练它（让大脑变聪明）。

📖 一个故事：教小孩认猫

想象你有一个 3 岁小孩（这就是你的神经网络——初始版本，啥也不会）。

🗣️ 小夏讲比喻

小孩（网络） → 你给他看一张猫的图片
小孩说"这是狗" → 前向传播（猜了一次）
你说"不对，这是猫" → 损失函数（告诉你猜错了）
小孩想"哪里看错了？耳朵？尾巴？" → 反向传播（找问题）
下次再看猫，他知道了"圆耳朵 + 长胡子 = 猫" → 训练完成 ✅

PyTorch 就是帮你完成上面整个流程的工具。 你只需要告诉它： "我要用什么样的网络？用什么数据？训练多久？"——剩下的自动计算。

二、核心概念：Tensor —— 神经网络的数据容器

🔢 什么是 Tensor？

Tensor（张量）是 PyTorch 里最基本的数据结构。
你不需要被这个高大上的名字吓到——说白了就是：一个装着数字的多维数组。

维度PyTorch 叫法生活中的例子
0 维标量 (Scalar) / 0D-Tensor一个数字：价格 3.5 元
1 维向量 (Vector) / 1D-Tensor一排行列：一周 7 天的气温 [22, 24, 23, …]
2 维矩阵 (Matrix) / 2D-TensorExcel 表格：10 行 × 5 列的考试成绩单
3 维3D-Tensor一张彩色图片 (高×宽×RGB通道)
4 维4D-Tensor一批彩色图片 (batch×高×宽×通道)
💡 记住这个

Tensor = NumPy 数组 + GPU 加速 + 自动求导。
如果你写过 Python 的 NumPy，那 Tensor 就是它的"超级进化版"——多了两个绝招。

🛠️ 基本操作速览

# 创建 Tensor
x = torch.tensor([[1, 2], [3, 4]])           # 手动创建
x = torch.randn(3, 5)                         # 随机正态分布
x = torch.zeros(2, 3)                         # 全零
x = torch.ones(4, 4)                          # 全一

# 形状操作
x.shape              # 看形状 (3, 5)
x.view(-1, 5)        # 重塑形状（像 rearrange）

# 运算 —— 和 NumPy 几乎一样
x + y, x * y, x @ y  # 加、乘、矩阵乘法
x.mean(), x.sum()    # 平均值、求和

# 和 NumPy 互相转换
np_array = x.numpy()
torch_tensor = torch.from_numpy(np_array)

💻 GPU 加速 —— Tensor 的隐藏技能

# 把 Tensor 搬到 GPU 上
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
x = x.to(device)     # 送到显卡
y = y.to(device)     # 计算自动在 GPU 上跑，快几十倍

这是 PyTorch 相对普通 Python 的一大杀器： 训练有大 GPU 加速，一次算几千几万个数字，而不是用 for 循环一个一个算。

三、自动求导 (Autograd) —— 魔法引擎

🗣️ 小夏讲比喻

没有 Autograd： 你想调一个参数，得自己拿笔算导数——又慢又容易错。
有 Autograd： 你只需要说"帮我算一下每个参数该调多少"，PyTorch 自动算好。

🔮 它是怎么工作的？

Autograd（自动求导）是 PyTorch 最核心的魔法。它会在你执行运算时，自动记录所有操作， 形成一个"计算图"。当你需要梯度时，它沿着这个图往回走，用链式法则算出每个参数的偏导数。 

# 核心只有两行
loss.backward()           # 反向传播：算每个参数的梯度
optimizer.step()          # 根据梯度更新参数

你完全不需要手算导数，不需要推导公式——PyTorch 自动帮你搞定了一切微积分。 这也是它比纯 NumPy 写神经网络方便一万倍的原因。

💡

一句话记住 Autograd

"只管向前算，PyTorch 自动记住你怎么算的；需要调参数时，它自己反向走一遍求梯度。"

学习范式 = 一整套关于"学习到底是怎么回事"的思路和做法。 不同的范式对应不同的"教法"。

🧠

深度学习属于 "连接主义"——是认知主义的一个分支。 它认为"学习 = 调整无数个神经元之间的连接强度"， 而 PyTorch 就是帮你做这件事的工具。

五、Dataset & DataLoader —— 把数据喂给网络

🗣️ 小夏讲比喻

Dataset = 你的食材仓库 —— 你知道食物（数据）放在哪
DataLoader = 自动服务员 —— 帮你按桌（batch）上菜

📦 Dataset —— 告诉我你的数据在哪儿

from torch.utils.data import Dataset

class MyDataset(Dataset):
    def __init__(self):     # 进货：把数据搬进仓库
        self.data = [1, 2, 3, 4, 5]

    def __len__(self):       # 报数：仓库里有多少货
        return len(self.data)

    def __getitem__(self, idx):  # 取货：给我第 idx 箱
        return self.data[idx]

你只需要实现这三个方法，PyTorch 就知道怎么用你的数据了。

🚚 DataLoader —— 自动分批上菜

from torch.utils.data import DataLoader

loader = DataLoader(dataset,
    batch_size=64,    # 一次端 64 道菜上桌
    shuffle=True,      # 打乱顺序（别总吃前几道菜）
    num_workers=4      # 4 个帮工同时搬货
)

🌊 训练时怎么用

for data, label in loader:          # DataLoader 自动送数据
    pred = model(data)                 # 猜一次
    loss = criterion(pred, label)      # 看差多少
    loss.backward()                    # 找问题
    optimizer.step()                   # 拧旋钮

🧰 常用预处理 (transforms)

数据不是原生就能喂的，得先加工一下：

操作人话解释
ToTensor()把图片变成 PyTorch 能吃的数字格式
Normalize(mean, std)标准化：把数字调到一个好学的范围
Resize((224,224))统一尺寸（不然没法一批处理）
RandomCrop随机剪一块（数据增强，防过拟合）
RandomHorizontalFlip随机翻转（让网络不看方向）

六、神经网络 (nn.Module) —— 搭积木

🗣️ 小夏讲比喻

nn.Module = 一套乐高积木。
基础块（Linear、Conv2d、ReLU）就像不同的积木颗粒。 nn.Sequential 就是按说明书把积木拼在一起——拼出一个造型，就是你的网络。

🏗️ 搭一个最简单的网络

import torch.nn as nn
import torch.nn.functional as F

class MyNet(nn.Module):                    # 继承 nn.Module
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 128)  # 第一层：784 → 128
        self.fc2 = nn.Linear(128, 10)   # 第二层：128 → 10

    def forward(self, x):                   # 前向传播
        x = F.relu(self.fc1(x))            # 第一层 + 激活函数 ReLU
        x = self.fc2(x)                    # 第二层
        return x

就这么简单。你定义 __init__ 里有哪些"积木块"， 在 forward 里描述数据怎么流过去——PyTorch 搞定剩下的。

🧩 常见积木块速查

📏

nn.Linear(in, out)

全连接层（密集层）。每个输入和每个输出都相连。y = Wx + b

🖼️

nn.Conv2d(C_in, C_out, K)

卷积层（图像专用）。滑动窗口扫描图片提取特征。

⚡

nn.ReLU()

激活函数：把负数变 0，正数保留。引入非线性能力。

📉

nn.Dropout(p=0.5)

随机"关掉"一半神经元——防止网络死记硬背（过拟合）。

🧊

nn.BatchNorm1d/2d

批归一化：让数据分布保持正常，训练更稳更快。

🔻

nn.MaxPool2d(2,2)

最大池化：缩小图片尺寸，留下最显著的特征。

🖇️ 快速拼装：nn.Sequential

model = nn.Sequential(
    nn.Linear(784, 128),
    nn.ReLU(),
    nn.Linear(128, 64),
    nn.ReLU(),
    nn.Linear(64, 10)
)   # 层层堆叠，像叠汉堡一样

Sequential 适合"一条路走到底"的网络——数据一层层往下传，没有分支。简单又直观。

七、线性回归 —— 最简单的神经网络

🗣️ 小夏讲比喻

线性回归 = 给一堆散点画一条最合适的直线。
你有一堆 2D 点 (x, y)，想让电脑找出 y = wx + b 里 w 和 b 的最佳值。

📐 公式：y = wx + b（初中知识）

符号意思房价预测例子
w（权重）"斜率"——x 每变 1，y 变多少面积每多 1㎡，房价涨 1.5 万
b（偏置）"截距"——x=0 时的基础值地皮基础价 50 万
x（输入）特征房子面积 80㎡
y（输出）预测值预测房价 170 万

🚀 PyTorch 实现

# 1. 造数据：真实关系 y = 2x + 1，加一点噪声
x = torch.linspace(0, 10, 100).view(-1, 1)
y = 2*x + 1 + torch.randn(100, 1) * 0.3

# 2. 定义模型：就是一个 Linear(1,1) —— y=wx+b
model = nn.Linear(1, 1)

# 3. 损失函数和优化器
criterion = nn.MSELoss()                        # 均方误差
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)  # 随机梯度下降

# 4. 训练循环
for epoch in range(200):
    pred = model(x)                              # 前向：用当前 w,b 预测
    loss = criterion(pred, y)                     # 看偏差

    optimizer.zero_grad()                         # 清零上一步的梯度
    loss.backward()                               # 反向传播：算梯度
    optimizer.step()                              # 拧 w 和 b

    if epoch % 20 == 0:
        print(f"Epoch {epoch}: loss = {loss.item():.4f}")

# 5. 看结果：w 接近 2，b 接近 1
print(f"w = {model.weight.item():.3f}, b = {model.bias.item():.3f}")

训练过程中，你可以看到损失值（loss）从几十一路降到接近 0，
w 和 b 从随机值慢慢逼近 2 和 1——这就是"学习"的本质。

💡

关键洞见

线性回归就是 没有隐藏层、没有激活函数的神经网络。 你弄懂了它，就弄懂了神经网络 80% 的核心流程：
前向 → 损失 → 反向 → 优化 → 重复。

八、手写数字识别 —— 第一个完整项目

MNIST 数据集：7 万张 28×28 像素的手写数字图片（0~9）。
这是深度学习的 "Hello World"——每个入门者都要做的项目。

🏗️ 完整代码

import torch
import torch.nn as nn
import torch.nn.functional as F
import torch.optim as optim
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

# ─── 1. 数据预处理 ───
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.1307,), (0.3081,))
])

# ─── 2. 加载数据 ───
train_data = datasets.MNIST(root='./data', train=True,
                            transform=transform, download=True)
test_data  = datasets.MNIST(root='./data', train=False,
                            transform=transform, download=True)

train_loader = DataLoader(train_data, batch_size=64, shuffle=True)
test_loader  = DataLoader(test_data,  batch_size=1000, shuffle=False)

# ─── 3. 定义网络 ───
class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 128)   # 输入层 784 → 隐藏层 128
        self.fc2 = nn.Linear(128, 10)    # 隐藏层 128 → 输出层 10

    def forward(self, x):
        x = x.view(-1, 784)                # 把 28×28 拍平成 784
        x = F.relu(self.fc1(x))           # 隐藏层 + ReLU
        x = self.fc2(x)                   # 输出层
        return F.log_softmax(x, dim=1)    # 转成概率分布

model = Net()

# ─── 4. 损失和优化器 ───
criterion = nn.CrossEntropyLoss()
optimizer = optim.SGD(model.parameters(), lr=0.01, momentum=0.5)

# ─── 5. 训练 ───
for epoch in range(5):                     # 所有图看 5 遍
    for data, target in train_loader:
        optimizer.zero_grad()
        output = model(data)
        loss = criterion(output, target)
        loss.backward()
        optimizer.step()
    print(f"Epoch {epoch} 完成")

# ─── 6. 测试 ───
correct = 0
total   = 0
with torch.no_grad():                    # 考试了，不记笔记
    for data, target in test_loader:
        output = model(data)
        pred = output.argmax(dim=1)      # 取概率最高的那个数字
        correct += (pred == target).sum().item()
        total   += target.size(0)

print(f"测试准确率: {100 * correct / total:.1f}%")   # 通常 > 97%

📊 网络结构视觉化

输入
28×28 → 784 → 全连接
784 → 128 → ReLU
激活 → 全连接
128 → 10 → Softmax
输出概率 → 预测
数字 3 🎯

一个只有 2 层全连接层的极简单网络，能到 97% 以上 的准确率。 这已经是 30 年前的技术了——现在更复杂的 CNN 网络能做到 99.8%。

九、训练流程拆解 —— 三步一循环

上面所有例子里，训练结构都是一样的。我把这 "永恒的三步"专门拎出来讲：

前向传播
model(x) → 算损失
criterion(pred, y) → 反向传播
loss.backward() ↻ 更新参数
optimizer.step()

🔁 三句话流程

🚀

前向传播

把数据送进网络，算出一堆预测值。
pred = model(data)

📊

算损失

拿预测值和真实值对比，算偏差。
loss = criterion(pred, target)

🔙

反向传播 + 更新

回传梯度 → 更新参数。
loss.backward()
optimizer.step()

📌 三个关键细节

🗑️

optimizer.zero_grad() 有什么用？

梯度默认会累积。不清零的话，上一批数据的梯度会和当前的混在一起，像上一道菜的油没洗锅就炒下一道。所以每次迭代前清零。

📵

torch.no_grad() 什么时候用？

考试模式。评估/测试时用——告诉 PyTorch"别记录梯度了，我只想快点出结果"。

📏

Epoch 和 Batch 的区别？

Epoch = 全部数据看了一遍。Batch = 一次看的数量。6 万张图，batch=64 → 938 个 batch 才完成 1 个 epoch。

📋 损失函数速查

损失函数用在人话
MSELoss回归（预测连续值）"猜得偏离了多少，平方后平均"
CrossEntropyLoss分类（N 选 1）"猜错的概率越小越好"
BCELoss二分类（是/否）"是猫不是猫，猜对了没"

🔄 优化器速查

优化器特点啥时候用
SGD基础版梯度下降简单任务、学习用
SGD + momentum带惯性，加速收敛大多数常规任务
Adam自适应学习率，"聪明版"新手首选，啥都能用
AdamWAdam 改进版现代推荐，尤其 Transformer
